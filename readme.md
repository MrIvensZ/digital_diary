# 📔 DigitalDiary

**DigitalDiary** — это приложение для ведения личного электронного дневника. Оно предоставляет графический интерфейс на базе `tkinter`, позволяет создавать, редактировать, просматривать и удалять записи. Данные надёжно хранятся в базе данных SQLite, а управление структурой БД автоматизировано с помощью SQLAlchemy.

---

## ✨ Особенности

- 🖥️ **Графический интерфейс** — интуитивно понятное приложение на `tkinter`.
- 🗄️ **Хранение данных** — все записи сохраняются в локальной базе `SQLite`.
- 🛠️ **Управление схемой БД** — использование `SQLAlchemy` для работы с моделями и `Alembic` для миграций.
- 🔍 **Базовые CRUD-операции** — создание, чтение, обновление и удаление записей.

---

## 🛠️ Технологический стек

- **Язык:** Python 3.8+
- **Графический интерфейс:** Tkinter
- **ORM:** SQLAlchemy
- **Миграции:** Alembic
- **База данных:** SQLite3

## 📝 Использование
После запуска **main.py** откроется окно приложения.

## Главное окно
Окно программы разделено на две функциональные части:

*   **Слева** — находится список всех созданных записей.
*   **Справа** — отображается содержимое выбранной записи или форма для её создания/редактирования.

---

## Основные действия

### 📝 Создать запись
1.  Нажмите кнопку **«Новая запись»** в верхней панели.
2.  Заполните поля **«Тема»** и **«Текст»**.
3.  Нажмите **«Добавить запись»** для сохранения.

### 👁️ Просмотреть запись
1.  В списке слева найдите нужную запись.
2.  Нажмите кнопку **«Читать»** рядом с ней.
3.  Содержание откроется в правой части окна.

### ✏️ Редактировать запись
1.  Откройте запись (следуя инструкции выше).
2.  Нажмите **«Редактировать запись»**.
3.  Измените тему или текст.
4.  Нажмите **«Ок»** для сохранения или **«Отмена»** для отмены изменений.

### 🗑️ Удалить запись
1.  Откройте запись.
2.  Нажмите **«Удалить запись»**.

> **Важно:** Подтверждение удаления не требуется.

## Навигация
*   **Закрыть просмотр** — нажмите на крестик (**❌**) в правом верхнем углу панели.
*   **Прокрутить список** — используйте колесико мыши или полосу прокрутки справа.
*   **Закрыть форму создания** — повторно нажмите кнопку **«Новая запись»**.

---

## ⚠️ Важно
*   Все записи сохраняются автоматически в базу данных.
*   Удаление происходит без подтверждения — **будьте внимательны**.
*   В поле текста поддерживаются переносы строк и вставка текста (сочетание клавиш `Ctrl + V`).

---

## Быстрые советы
*   Список обновляется автоматически после любого действия.
*   Для очистки полей при создании записи используйте кнопку **«Очистить»**.
*   Если правая панель пуста, откройте существующую запись или создайте новую.
